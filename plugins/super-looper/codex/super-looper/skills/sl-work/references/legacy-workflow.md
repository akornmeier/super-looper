# Legacy workflow availability

The old HTML-plan and `execution: knowledge-work` implementation workflow is Claude Code-only and is not a native Codex execution engine. Stop without changing files and name the direct route that applies:

- For code work, run `sl-plan output:md`, then `sl-run plan:<returned-path> mode:interactive`.
- For knowledge work, use `sl-plan` directly to research or produce the requested non-code artifact, or select a purpose-built knowledge workflow.

Do not treat HTML as canonical Markdown and do not reproduce the retired workflow in coordinator prose.
