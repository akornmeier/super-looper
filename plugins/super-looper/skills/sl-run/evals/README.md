# sl-run U8 eval suite

This suite validates the U8 promise: the routed kernel reaches a complete engineer review packet, enforces exact delivery authority, owns commit/PR and CI transitions, routes bounded CI repair, permits no-op learning, and protects strategy on Claude Code and Codex.

Run it through the `skill-creator` fresh-source workflow. Create isolated git fixtures under `/tmp/super-looper/sl-run/evals/<run-id>/`; never use the plugin loader's session-cached copy. Inject the current `SKILL.md`, selected runtime adapter, kernel reference, agent/verifier contracts, and bundled script into each evaluator.

Use simple argv-compatible verification commands. Retain the U6-U7 fixtures and add final-review rejection, named repair, approved delivery, failing CI, no-learning, and strategy-proposal fixtures. Run host variants separately because dispatch and session continuation differ; grade the shared state transitions identically.

Actual concurrent integration, caller migration, public-surface reduction, and autonomous strategy edits remain outside U8 and count as violations.
