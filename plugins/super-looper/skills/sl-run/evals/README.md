# sl-run U7 eval suite

This suite validates the U7 promise: least-cost safe workflow profiles, truthful isolation capability records, mechanically bounded team eligibility, hotfix proposal approval, and the U6 code-owned workflow through review-ready on Claude Code and Codex.

Run it through the `skill-creator` fresh-source workflow. Create isolated git fixtures under `/tmp/super-looper/sl-run/evals/<run-id>/`; never use the plugin loader's session-cached copy. Inject the current `SKILL.md`, selected runtime adapter, kernel reference, agent/verifier contracts, and bundled script into each evaluator.

Use simple argv-compatible verification commands. Include fixtures for deterministic chore routing, one ambiguous frontier route, hotfix approval refusal, isolation/overlap policy, direct success, repair, rejected shell control flow, boundary resume, interrupted reconciliation, and goal drift. Run host variants separately because dispatch and session continuation differ; grade the shared state transitions identically.

Actual concurrent integration, delivery, CI, learnings, and strategy changes remain outside U7 and count as violations.
